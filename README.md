# Appexy - Modern Landing Page

A sleek, premium, and fully responsive landing page for **Appexy**—a modern activity management application. Built using modern web technologies featuring a stunning user experience, rich micro-interactions, dark mode support, and an interactive pricing system.

## 🚀 Live Demo

Check out the live deployment of this project:
👉 **[Appexy Live Demo](https://omartantawy360.github.io/tailwind-project/)**

---

## ✨ Features

- **Dynamic Theme Switcher**: Full support for system-based or manual Dark/Light mode with smooth transitions.
- **Micro-interactions & Animations**:
  - Custom floating background bubbles for enhanced aesthetic depth.
  - Interactive 3D flip cards in the pricing section.
  - Hover glow effects, scaling cards, and slide-in animations.
- **Interactive Modals**: Fully functioning modal popups for login and signup actions.
- **Pricing Selector**: Toggle seamlessly between monthly and yearly pricing tiers.
- **Fully Responsive**: Optimised experience across desktop, tablet, and mobile devices.
- **Modern Tech Stack**: Powered by Tailwind CSS v4's modern features.

---

## 🛠️ Tech Stack & Libraries

- **HTML5** & **Vanilla JavaScript** (DOM manipulation and animations)
- **Tailwind CSS v4** (Advanced utility classes and CSS variables design system)
- **FontAwesome v7.0.1** (Icon typography)

## ⚙️ Development & Setup

Follow these steps to run the project locally or compile tailwind styles:

### 1. Clone the Repository
```bash
git clone https://github.com/omartantawy360/tailwind-project.git
cd tailwind-project
```

### 2. Install Dependencies
Make sure you have Node.js installed, then run:
```bash
npm install
```

### 3. Build & Watch Tailwind CSS
To build the CSS once for production:
```bash
npm run build
```

To watch for changes and build automatically during development:
```bash
npm run dev
```
